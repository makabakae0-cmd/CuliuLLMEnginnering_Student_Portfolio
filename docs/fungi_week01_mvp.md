## 产品范围（v1）
- 核心：输入真菌参数 -> 输出结构化课堂讲解。
- 核心用户：学生、教师。
- 不做：复杂对战、文献级检索、复杂Agent编排。

## 信息架构
1. 登录页
2. 学生工作台
3. 教师工作台
4. 解说生成页
5. 历史记录页
6. 设置页

## 关键流程
### 学生流程
登录 -> 输入参数 -> 生成讲解 -> 保存记录 -> 查看历史

### 教师流程
登录 -> 管理课堂样本 -> 下发任务 -> 查看学生提交

## 接口草案（v1）
1. `POST /api/auth/register`
2. `POST /api/auth/login`
3. `GET /api/health`
4. `POST /api/explanations/generate`
5. `GET /api/explanations/history`
6. `GET /api/templates`
